# Positive rebate candidates — two-stock isolated review

These are reference-informed reconstructions, not original scans or a universal film color standard. No v3 asset or production file was replaced. The reference photographs are not App assets.

## Ektar 100
Primary: Film Speed Lab FAQ sample gallery, Durst Sigma Plus, “With borders 2 / Durst.JPG”.
https://filmspeedlab.com/pages/faq
https://drive.google.com/file/d/1YbIwmlvt340kpfkXwZJDgaFfRF5XgA3z/view
Viewed: normal positive statue/sky, KODAK EKTAR100 readable, nearly black rebate with warm light lettering/DX; holes are dark, nearly blending with material. Candidate uses this color family, not a calibrated exact RGB.
Corroboration: LoMit's same physical negative, positive, and tonally corrected positive on Wikimedia Commons. The corrected positive has near-black/deep-red rebate and yellow lettering, whereas uncorrected inversion is cyan. This is a handheld photographed strip, not a lab scan. Prior orange candidate erroneously retained negative-display material color beside a positive picture.

Existing LoMit CC BY 4.0 attribution/provenance remains applicable to the prior reference-informed construction. No source photograph pixels were pasted into this asset.

## Change contract
- Both independent 1520x1400 straight-alpha sRGB assets retain v3 alpha bytes, aperture, perforations, original lettering shapes, 25/25A, all logical module bits and coordinates.
- Each carries hole_matte_srgb8 [0,0,0]; only these two assets. Alpha-zero RGB remains zero. Matte belongs to the final compositor, not a new painted outline.
- Reference-informed per-stock palette mapping, NOT RGB inversion. Original material/text texture is retained with a bounded color transfer. Entire verified DX masks receive class-specific reference colors and bounded original texture; no module relayout or point-patching.
- bit1 changes from dark to light. New version and sampling polarity are explicit. Native full nonzero-alpha logical checks pass; codec/dense output validation is PENDING. v3 encoded results do NOT validate these changed colors.
- Early r1 continuous mapping failed Gold contrast and was rejected locally. Use r2 only.
- Review board uses BOX reduction and a gray empty aperture placeholder, NOT a final photo compositor. Final photo preview must use the App linear-light compositor with per-asset matte.
- Source scanning exposure, black-point, color correction and monitor display vary. This is a bounded reconstruction of observed examples, not proof all real scans share these values. Other sixteen assets are untouched, not implicitly approved by these two references.
