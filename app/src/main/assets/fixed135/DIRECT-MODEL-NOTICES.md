# Direct negative border presentation

Eleven monochrome-track physical stocks use separately derived D65 model materials.
The minimum normalized dye density plus the profile base spectrum supplies the base.
Channelwise maximum density is a reference contrast bound for markings, not a measured
factory latent exposure; channel maxima need not come from the same exposure.
Missing spectra follow the engine convention; linear sRGB is clipped only for display.
Existing authored glyph/texture coverage is a continuous RGB-derived approximation,
not a recovered physical density layer. Original alpha, geometry and encoded DX bits remain.
Portra800 push variants share the base physical frame. Hole white/black is the user's
aesthetic preference, independent of the negative material. Reversals remain unchanged.

Real stock references corroborate selected identities and tonal ordering, not calibrated
RGB. PRO400H, Vision3 50D and Verita actual-image evidence gaps remain in the public audit.
Fuji C200/XTRA additionally use manufacturer-supported red/green track categories
with profile-separated dye models, not measured factory exposures. PRO400H keeps a
dark single-line illustration; its actual line color remains unverified. See
FUJI-DIRECT-MODEL-NOTICES.md. No unified orange or RGB inversion is used.

All45 previous material contracts are immutable, including existing queued direct jobs.
New queue appearance contracts select this material only after the scientific image is
complete. The border never enters exposure metering, film processing or checkpoints.
