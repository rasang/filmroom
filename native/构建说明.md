# 原生引擎构建说明

这是随暗房首版体验包提供的修改后 GPL 对应源码，不是未经修改的上游仓库。保留 `LICENSE`、`SPEKTRAFILM_LICENSE.txt`、`PORTING.md`、`PORT_MANIFEST.json` 和数据声明。英文法律文本保持原文。

## 已验证的构建环境（本次仅 Linux 云端；未测试 macOS 构建）
- 完整 JDK 17；Android SDK 35 / Build Tools 35.0.0；Gradle Wrapper 8.11.1。
- Rust / Cargo 1.88.0；Android NDK r27c（27.2.12479018）。
- 原生目标：`aarch64-linux-android` 和 `x86_64-linux-android`，链接 API 26；应用最低 Android 10 / API 29。
- CPU 路径与受限可选 Adreno/Vulkan 密度计算；内部 f64，JNI / 文件边界 f32；不需要 Python、服务器、CUDA 或桌面 GUI。

先在自己的构建机器上安装所需工具、两个 Rust Android 目标，并按其条款配置 SDK / NDK。本脚本不自动安装、下载或接受许可。

```sh
export ANDROID_NDK_HOME="$ANDROID_SDK_ROOT/ndk/27.2.12479018"
# 确保 PATH 选中 Rust / Cargo 1.88.0
bash native/build-native.sh --check
bash native/build-native.sh all
cp -R native/artifacts/jniLibs/arm64-v8a app/src/main/jniLibs/
cp -R native/artifacts/jniLibs/x86_64 app/src/main/jniLibs/
./gradlew testDebugUnitTest assembleDebug lintDebug
```

`CARGO_HOME`、`RUSTUP_HOME` 和 `CARGO_TARGET_DIR` 可使用你自己的隔离目录。脚本使用 `--locked` 与随附 `Cargo.lock`，首次获取编译依赖可能需要网络；应用运行本身没有网络权限。

Android 两个库实际用此脚本在 Linux 交叉编译。脚本提供 macOS 路径分支，但没有在 Mac 执行验证。两个库使用 16 KiB 链接对齐参数；这不等于已完成 16 KiB 安卓设备运行测试。

## 源码与产物核验
`PORT_MANIFEST.json` 记录修改文件，`DATA_MANIFEST.json` 记录数据。交付根目录的 `验证/` 保留主机测试、最终库哈希和构建证据。

源码包不包含私人签名密钥。你重新构建并安装自己签名的 APK，不能覆盖其他签名的已安装包。保留自己的密钥才能持续升级。Release 构建默认输出未签名 APK，签名应使用你自己的本地工具和密钥。

不同工具路径或构建环境可能生成不同二进制哈希。提供的是已验证、可重复执行的源码构建流程，并不宣称跨机器字节完全可复现。

## 精简 ARM64 安装包

完整源码默认同时包含已构建的 ARM64 与 x86_64 库。仅给 64 位 ARM 手机分发时可使用正式 Gradle ABI 过滤（不手工修改签名 APK）：

```sh
./gradlew :app:assembleDebug -PfilmroomAbi=arm64-v8a
```

此包不能用于 x86_64 设备。0.1.2复用0.1.1的本地 debug 签名，可覆盖安装0.1.1；不同密钥的0.1.0不兼容。不要把签名私钥放入源码发布包。

为适配移动聊天附件大小，Android Gradle Plugin 配置 `packaging.dex.useLegacyPackaging = true` 压缩 DEX。未删除任何算法/数据，也未改变任何解压后的 APK 条目；原生 `.so` 仍采用不压缩直接映射，并保留 16 KiB ELF / ZIP 对齐。相同调试密钥重新签名，最终 ARM64 包约 19.1 MB。
