## 本轮更新
- vivo 品牌 DNG：按已验证结构校验色调曲线端点，保留未应用相机色调曲线的明确说明；读取真实 RAW，不使用嵌入预览冒充结果。仅受测能力范围，不宣称所有 vivo/SuperRAW 兼容或与相机相册一致。
- 首页面采用原创 CP-Lift 风格模型插画；保留模型来源说明，不是实物照片或厂商背书。
- 横屏编辑页隐藏状态栏，保留导航及系统安全边界；竖屏恢复正常系统栏。折叠屏展开或窗口可用宽度至少600dp时默认左右分栏，窄外屏/分屏回到紧凑布局；主机尺寸验证不等于所有折叠设备实测。
- 短枚举参数拨轮松手及时选中，保留触摸、无障碍与取消语义；胶卷仍点击选中，不恢复滚动选胶卷。
- 扫描阶段完成后从真实扫描结果生成小预览并切换成片展示；不按虚构进度阈值提前显示。之后的柔光/锐化等仍可能改变最终成片。第三阶段光效动画加强。
- 新安装默认关闭“新导入时重置参数”和“冷启动恢复上次照片”；不覆盖已有持久用户偏好。

## 不变的边界
原图不覆盖，默认原尺寸导出。局部放大预览仍为 1536 工作网格上限；不新增 HDR 增强/保真或原图密度预览。大图、复杂光效及批量导出可能发热、耗电并受到系统温控/后台限制。测试依据为 Linux 算法/JNI 与 Android 主机界面测试，不等同真机全流程或手机性能保证。
