Filmroom Perf 0.1.19-opt.3 私人测试说明

安装
这是独立的 Filmroom Perf · 优化测试版（dev.filmroom.perf），不会覆盖正式版或 JXL 测试版。可以覆盖升级已有 Perf；旧设置会保留。新安装的优化候选默认全部关闭。照片需在 Perf 内自行导入，不会复制另一个应用的私有数据。

这次重点
设置 → 精确优化测试，新增“64 · 精确柔光核生成”。它减少柔光核的重复计算，不改变柔光半径、归一化求和顺序、浮点精度、颗粒随机数或画面效果。适用于导出相机柔光和印相柔光；不宣称所有预览都已接入。
原有 1、2、4、8、16、32 保留。没有降低画质的速度模式，也没有新的全流程 GPU 渲染。

最有用的对照
1. 开启柔光并使用非零强度，否则 64 没有可加速的工作。保持同一照片、胶卷、全部参数、颗粒种子、输出尺寸和格式。两组都勾选“CPU 精确对照”，避免 GPU 路由不同。
2. A 组：勾选 1、2、4、8、16、32，关闭 64（日志 mask=63）。完成一次全新导出，不从暂停任务续跑。
3. B 组：只增加勾选 64，其他完全相同（mask=127）。再次全新导出。
4. 最好按 A→B→B→A 测试，手机每次恢复相近温度，保持前后台、充电状态相同。不要仅凭一次比较判断稳定收益。
5. 设置底部有最近完成任务耗时。导出后尽快分享诊断日志，并说明 A/B 顺序、是否发热、有没有手动取消或退后台。新日志会记录真实检查点心跳，但心跳不是已完成像素；系统退出原因只在能够可靠关联时记录，无法判断时保持未知。

也可点“全部候选关闭”取得原始算法基线；CPU 精确对照选项独立保留，请确认两边一致。每次开始渲染时固定；切换不会改变已经开始渲染的任务，尚未开始的排队任务会使用启动时的设置。

目前证据
云端 CPU 的代表性 Cinebloom 核（4000×6000 的尺寸设置，strength 0.24、size 1.0、35mm，核半径 1999）三次测试中，单独生成完整 RGB 柔光核的中位耗时从 6214 ms 降到 2746 ms，减少 55.8%。每次全部 47,976,003 个 f64 系数逐位相同。此项只计柔光核，不含 FFT、解码或写出，不能当成手机整张导出提速。
手机实际整图耗时、发热和峰值内存仍需实测。大半径 FFT 的空间需求没有因本次核优化消失。

分享与隐私
新增诊断仅含固定分类、阶段和数值，不添加照片名、路径、URI、EXIF、PID 或进程名。退出诊断不能追溯解释安装本版之前的中断。原图不会覆盖。

本轮验证范围
原生核心 145 项、集成 59 项、模型专项 5 项通过；另有 90 组完整输出位一致比较和 11 项真实主机 JNI 检查。Android 默认应用身份检查 8 项、Perf 主机检查 74 项通过；9 项需单独大图夹具的可选 12–50MP 导入测试本轮未执行。lint 无错误，80 项既有警告。主机测试不等于实机验收。
