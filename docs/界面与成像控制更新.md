# 界面与成像控制更新

## 相机式编辑布局

黑底大预览，顶部导入、撤销、重做、导出与诊断入口；底部圆角分类栏。分类按胶片、调整、光效、颗粒、显影、印相、扫描排列，可横向滚动，当前分类与工具自动滚入可见区域。

一次只展示一个参数的尺规或选项。精细参数从菜单选取；说明按信息按钮阅读，不把长表单堆在照片下面。短操作不拆成竖排，不用省略号隐藏选项。完整文件名在照片信息里，避免长文件名挤占预览。

竖屏为上下布局；横屏无论是否平板都为左图右工具。大字号工具区可以滚动，同时保留照片空间。旋转保留参数、分类、选中工具与缩放状态；配置变化不取消导出。

## 真实阶段导出动画

独立弹窗用胶片动画表现当前真实处理阶段，包括读取、测光、镜头柔光、胶片曝光、光晕、显影、颗粒、印相、扫描、编码保存。阶段可重复或快速结束，不为了动画延长计算，不伪造全局百分比。

保留文字、取消与诊断入口；取消等待清理，完成或失败关闭弹窗。系统关闭动画时使用静态图案。

## 成像控制

- 镜头与印相柔光各自支持柔光、黑柔、白柔、电影柔光；可独立关闭。
- 光晕颜色与多次反射、胶片散射分开控制。
- 颗粒包含分层、染料云、结团与各色层粒子面积比例；不是色彩饱和度。
- 印相滤色、预闪、自动/手动中和、光源与相纸密度曲线属于印相路径；直扫时禁用。
- 反转片直扫得到正像；负片直扫不反相。负片直扫不支持扫描黑白场校正。
- 导出可选 sRGB、Display P3、Adobe RGB (1998)，预览保持 sRGB；宽色域导出关闭仅适用于 sRGB 的色域映射。
- GPU 开关仅请求 Adreno 部分密度阶段加速，实际设备、精度与耗时门槛决定是否使用；不能把开启等同于已加速。

参数参与本机保存、撤销/重做及类型白名单诊断。预览与原尺寸导出使用同一参数合同。

## 验证边界

包含 Robolectric native-graphics 对实际 Activity 的 28 张整页渲染：320×640 与 740×320、常规及 2 倍字体、7 个分类。使用合成测试图片，不代表真机照片处理、GPU 性能或真机视觉验证。最终测试数量与 native 算法验证以构建记录为准。
