# 前置片边成像候选

本分支从 code55 / 54a2bcea 开始。此前编辑器和导出均在胶片成像完成后再添加片边、裁切与日期。

## 新顺序

1. 保留原始线性 RGB，单独用于自动曝光测光。
2. 使用冻结的构图与片窗几何，把原图与既有片边素材合成到线性 sRGB 输入。日期和拍摄参数也在这一阶段加入；RAW 的浮点精度与大于 1 的高光值不经过 8 位中间图。
3. 整幅合成图共同经过镜头/扩散、曝光、胶片显影、颗粒、印相/直扫和扫描阶段。原生计算的像素间距来自片窗尺寸，不因外围片边扩大而改变颗粒或光学尺度。
4. 最后只恢复素材明确标记的透明孔洞/无乳剂区域为既有白/黑显示底色，不再叠加片边、画面或日期。

白孔不作为高亮场景输入。孔洞 alpha 与照片孔径 alpha 有不同含义，不能从 RGB 颜色猜测；白色印字仍会进入成像流程。120 素材为不透明连续片边，没有齿孔遮罩。

## 外观边界

这是用户要求的共同成像艺术效果，不是原始胶片密度重建。现有素材是输出参考外观，按正像/负片透射路线制作，进入流程后可能再次染色、反相或改变对比。没有声称还原实物片边曝光、乳剂厚度或光谱密度。用户应在视觉对照后决定是否采用。

## 持久化与回退

`filmBorderStage=1` 为新前置模式；`0` 为旧后贴模式。缺少字段的历史参数/队列任务解释为 0，以免旧检查点和用户预设的视觉语义被偷偷更换。新开片边时选择 1。恢复上次活跃编辑会话时，已开启片边自动迁移到 1，无需关闭重开；这一步仅作用于编辑器会话恢复，不改写历史队列或已保存配方，处理参数重置保留已选顺序。内部可以显式保留 0 进行 A/B 对照；本候选没有添加第二套用户界面开关。

新模式通过 `preImagingAbi=1` 协商，不兼容的旧原生库会明确停止。新输入契约进入 native 缓存与检查点身份，测光文件路径不进入日志/缓存键。原图与合成文件是两个文件，原图保持不变。新模式暂时不启用已编码成品复用缓存，避免跨顺序复用。

## 预览与交互

快速预览和导出使用同一浮点行合成逻辑和孔洞遮罩。完整框尺寸纳入预览内存预算。新模式的构图移动使用上一张已成像结果作片窗内的临时几何近似，松手后重算完整成像。只有精确结果可导出，旧请求不得覆盖新拖动；不能使用未成像原图补充旧裁切之外没有的内容。本分支提供已成像结果和显式模式接口，旋转近似实现由构图分支共同集成，需单列交叉验收。暂时关闭新模式的局部细节预览与 1536 GPU refinement，直到这些路径具备同样的合成输入和坐标契约。无框与旧模式不变。

直方图在前置模式只采已成像片窗，排除外围片边，不对已裁切结果二次裁切或旋转。已共同成像的日期像素无法单独剥离，若日期在片窗内会计入显示亮度统计；这不是自动曝光测光。

预览与原尺寸导出仍有既有差异：预览有分辨率上限，颗粒采样网格不同；现有预览与导出的全图测光采样策略也不完全相同。本改动保证测光不读边框，不承诺最终像素逐个相同。

## 资源与取消

导出按行合成，不分配原尺寸整图位图；保留原始输入，新增一个全框 float 临时文件。原生预算按完整框重新规划，最终孔洞恢复也按行完成。输入/遮罩写入使用 `.part` 与原子发布，失败/取消不发布半图，并清理本轮临时文件。预览复合缓冲区与素材的内存租约覆盖 JNI 运行和结果接管。

测试与本轮实际结果记录在候选验证报告，不能将纯主机测试或编译检查当作 Android 真机验收。
