# beta33 后的功能风险与诊断覆盖

本次以 `336d6620`（beta33）为基线，不宣称下面风险均已真机复现。日志在本机既有诊断存储中，用户主动导出时才进入诊断包；不新增网络上报。

## 重点：照片动效 / Live 导出

| 风险点 | 诊断覆盖 | 验证边界 |
| --- | --- | --- |
| 原图授权失效、封面可读但原图不可读 | 输入边界、成片解码、原图解码、构图、Live 视频提取分阶段记录 | URI/路径不入日志；具体文件入口仍需设备验证 |
| 打开动效选择弹窗后快速取消、切图、进入后台 | 预加载开始、耗时、最后阶段、取消/失败/成功 | 已有单次 token、记录匹配、generation/epoch、过期清理保护；需真机压测 |
| 原声无轨道/解码异常与真实静音混淆 | 音轨不存在、缓存命中、音频解码/混音/编码、降级原因 | 保持原有降级策略；不采集声音 |
| 预览声画准备不同步、无音频焦点、播放器错误 | 焦点拒绝、播放器数值错误、迟到原声接入 | 不逐帧记录 |
| 高分辨率内存、GPU纹理、编码器能力与超时 | 既有尺寸预算、编码器候选，加初始化阶段/耗时、输出完整性汇总 | beta33 的 >2048 构图修复保持不变 |
| 厂商Live格式选择和实际封装失败 | 预检、选定profile/support编号、恢复清理、提取封面、封装、验证、发布 | 预检通过不等于第三方相册可播放 |
| 保存失败、取消、清理失败 | 固定SDK错误类别、最后执行阶段、结束结果、清理失败 | 不隐瞒发布失败；不把分享/预检当成保存成功 |

## 重点：配方

- 保存/删除/合并：读取、校验、原子写入；区分重复名、容量满、损坏、版本不兼容、写失败。
- 应用：参数解析及胶卷支持校验、提交；识别照片/参数已变化导致的过期拒绝，取消与失败分开。
- 二维码分享：编码、二维码渲染、分享海报、自检、文件写入、打开系统分享面板。打开分享面板不代表第三方接收成功。
- 二维码导入：区分相机、相册、文本；图片读取/解码、二维码解码、兼容校验、命名确认、保存。不记录二维码正文。
- 扫码相机：权限拒绝、首次相机错误、相册切换、退出；不记录每帧失败识别。

## 其他功能

- 备份/恢复：补足读取/解析/校验、配方写入、历史记录写入、设置写入的阶段与条数，标识是否已开始写入，取消不误报为普通失败。保持各存储原子写入与重试去重策略，不扩大为完整媒体备份。
- 构图/片边/调平：重点保留像素几何一致性、高分辨率、旋转和取消相关既有回归；此次不增加拖动逐帧日志。
- 直方图：需检查采样区域排除片边、构图提交后旧帧不误用、调平后区域正确；不记录直方图 bins 或像素统计，以免将图像内容衍生数据写入日志。
- RAF/RAW：既有导入日志包含入口、头部格式、路由、尺寸/预算和固定codec错误。样片覆盖不等于所有厂商变体支持；本次不混入未授权的解码器修复。

## 隐私与体积

只允许固定枚举、技术尺寸/耗时/数量/错误码；不记录照片、音频、文件名、完整路径或URI、配方名、配方参数、二维码载荷、自由文本异常或堆栈。复用原有容量/时间窗口限制。编码逐帧DRAW/PRESENT/DRAIN不新增日志，扫码帧不新增日志。

## 验证状态

438 项相关回归及另 5 项日志队列 barrier/分享测试全部通过；124 项配方发布门禁通过；完整 lint 为 0 error、105 条既有 warning；release APK 构建通过。未进行真机厂商相册兼容或真实硬件编解码验证。

## 审查中处理的边界

- 新增 UI/音频回调日志使用有界单消费者 IO 队列；单 trace 最多64条待处理记录，全局最多64个排队 trace。分享日志前等待 barrier，避免刚失败就分享时漏掉已入队的终态。超载优先不阻塞功能，记录队列拒绝入队次数和单 trace 丢弃事件数；极端过载仍可能缺失日志，不能据“无日志”断定操作未发生。
- 配方分享二维码在后台生成后遇到页面关闭/暂停，未交付给 UI 的位图会回收；增加对应取消/失活测试。
- Live SDK 在已提交相册后、从 IO 返回调用方前被取消的机制风险单独记录 LIVE_COMMITTED。已用一次性已提交结果槽修复返回交接，不重跑发布；提交前取消继续回滚。生产 helper 竞态测试不等同于真实相册复现。
