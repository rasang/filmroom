# beta35 匿名流程关联

在 beta34 的分阶段诊断上补充跨子操作关联。流程标识只使用随机正整数，不由照片、路径、URI、配方 ID、内容或参数生成。原有单操作 `run + operationId` 继续保留；新字段用于把多个操作串成同一流程，不替代每个操作的结果。

## 配方

`recipeCorrelation` 从相机/相册扫码进入解码、校验、确认与保存，两个导入入口均传递。相机页面同进程配置重建保留关联；进程重启后的旧 token 不受信任，重新生成。

同进程内刚导入并保存的配方可通过有界内存映射关联后续应用。映射不写盘、不出现在诊断文件，删除成功后清除。最多保留 200 条导入关联及 512 个已签发 token；超出范围或重启后允许新建关联，不宣称跨安装/跨进程追踪。

## Live / 动效

预加载、输入解码、音频准备/播放与动效预览沿用所在页面的匿名关联；相邻页面各自独立。每次导出使用新关联，并通过 parentCorrelationId 指向页面关联，视频编码、预检、Live 封装/发布沿用该导出关联。各自 operationId 与起止结果仍保留以区分子操作。

输入格式复用业务 ImageDecoder 已解析的 MIME 映射成固定格式枚举，不为诊断额外打开媒体或读取文件。解码未进入 header 回调、未知或不支持的类型记录 UNKNOWN；不以文件名或 provider 声明猜测，不输出 MIME 原文、头部字节或媒体地址。

## 边界

日志仍是本机诊断且由用户主动导出。不新增网络上报。队列超载、历史窗口清理或进程退出可能导致日志不完整。关联字段不是文件身份，不可据它断言两次操作使用了同一照片或相同参数。

普通预览原有 `scienceFingerprint` 是成像设置白名单的确定性摘要，并非新随机流程标识；本次不复用它，也不扩大其记录范围。

## 验证

459 项相关主机测试全部通过，126 项配方发布门禁通过。完整 arm64 lint 为 0 error / 106 warning（包含 arm64-only 对 ChromeOS x86_64 的提示），arm64 release 构建通过。

新增格式测试使用真实 PNG 字节通过 ImageDecoder ByteBuffer source 获取头类型。Robolectric 的 ContentResolver 原生文件描述符入口不支持此主机运行，已保留初次失败记录；不声称真机 ContentResolver、OEM 相册或编解码硬件已经验证。未因主机限制改生产代码。
