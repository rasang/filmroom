# 0.1.22-beta3 测试包候选

本轮候选基于 code54，versionCode 为 55。此文件描述源码范围，不能单凭
本文件认定 APK 已构建、签名或通过设备验收；最终结果以对应打包记录为准。

## 本轮变化

- HP5、T-Max、Tri-X 三款 120 的日期/参数印字。
- 融合生成精确预览与交互片边，减少白孔切换中的重复边框采样。
- 半透明照片亮度直方图，缩为 100×44dp；不拦截照片手势，不参与导出。
- 离线预设二维码分享，支持相机或系统选图读取。导入须确认，保存为新
  预设，不覆盖同名项目，也不立即应用到当前照片。
- 保留预设完整字段与旧二维码兼容检查；二维码编解码和 UI 两类加入
  发布必跑门禁。
- 富士 RAF 的 Bayer/X-Trans 导入候选。仅当 ARM64 codec 从匹配源码成功
  重建并装入最终 APK 时，测试包才可声明包含此项。

## RAF 范围

主机验证覆盖九个正向样本，包括 X-A1、X-A3、X-Pro1、X-T2、X-T20、
X-T5、X100VI 的指定编码。不能据此声明所有富士机型、16-bit RAF 或 GFX
支持。52MP 传感器上限仍保留；GFX 超限及旧 Super CCD 布局会拒绝。
X-Trans 使用基础插值，不等同于富士机内 JPEG/胶片模拟；Android 导入、
导出、生命周期和内存压力仍需用户设备测试。详见 [RAF说明](FUJIFILM_RAF.md)。

## HEIF 分块路径未启用

候选源码包含实验性的串行分块实现，但生产入口继续使用 `gridEnabled=false`，
没有设置开关自动启用它，现有 HEIF 导入行为保持不变。主机规划器/模拟测试
不等于 Android 解码或 PSS 测量，也不证明大图完整分辨率导出完成。
在设备解码、颜色/接缝、旋转、内存及完整导出验收前，不将其标为已交付的
大图省内存优化。详见 [HEIF候选说明](HEIF_GRID_STREAMING.md)。

## 不变项和验收边界

应用 ID 仍为 `dev.filmroom`，计划沿用原发行证书以支持覆盖安装。原生
胶片引擎未改，诊断 BUILD12/INTERFACE2 保持匹配；RAF 的 codec 单独重建。
没有 GitHub 发布授权。交付前仍须校验源码/ELF/JNI/资源/DEX/版本、原签名
和分卷重组哈希，并保留所有未通过或未执行的检查。

历史原生 core 两项失败及完整 GPU film-engine harness 未执行状态不因
本轮整合而改变。本轮不宣称真机、Adreno 或手机性能验收通过。
