# 0.1.22.2-beta4 (108)

Experimental export-only memory admission: use one third, rather than one quarter,
of `availableBytes - thresholdBytes`, rounded down to MiB. Retain the 1024 MiB
ceiling, 128 MiB minimum admission, low-memory refusal and invalid-headroom checks.
Preview and import retain their existing one-quarter / 512 MiB policy. Native
allocation estimates, GPU binding limits, reservation gates and fallback rules are
unchanged; this changes a planner budget, not physical GPU memory or a promise of
faster rendering.

For example, 2376 MiB of net headroom admits 792 MiB instead of 594 MiB.
This beta requires real-device testing for performance and memory-pressure impact.
