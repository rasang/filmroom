# 0.1.22.2-beta1 (105)

## Scope

Large GPU diffusion fields that fail joint memory admission or the storage-binding limit now use an export-owned disk backing. Ordinary fields keep the existing resident path. This does not remove device capability checks, budget limits, or uncertain GPU completion protection.

- Full-resolution Front/PrintLinear taps remain budgeted tiles.
- Downsample sums are updated one small row at a time, preserving global `d` and partial-cell means.
- The finite GPU FIR blur uses budget-selected full-width stripes (maximum 512 core rows), per-component halo, original coefficients and f64 accumulation order. CPU FFT/IIR was not changed.
- Each stripe accumulates all Gaussian components before writing once. Final camera/enlarger fields are immutable files; downstream GPU tiles load only their bilinear footprint.
- Joint blur estimate: 192 bytes per expanded small pixel, 96 MiB fixed, 32 MiB additional margin, plus retained-field/kernel reservations. Binding limits are independent. When no legal full-width stripe fits, admission still fails safely; horizontal subdivision is not introduced here.
- Field-window caps reserve host crop, GPU field and upload staging (36 bytes per admitted pixel). They are checked before allocation.
- No early negative worker is launched on this path. Resident-field/FilmLog reuse is disabled for disk fields in this beta to avoid reading/copying an entire backing file into memory or reusing an incompatible identity.
- Storage preflight, exclusive temporary directory and cleanup guard protect failed/cancelled attempts. Disk-backed failures are terminal rather than silently retrying CPU. Backend submission uncertainty retains the existing guard.

## Verification

Tests use Mesa llvmpipe software Vulkan executing the real Rust/WGSL implementation, not Python. This is a correctness check, not an Android hardware performance measurement.

- Glimmerglass and Black Pro Mist, each 54 components, nonzero warmth, seven-row stripes: field output matched original GPU whole-field output (maximum error 0).
- Odd-size downsample, partial cells and tile addition order matched the original accumulator exactly.
- Disk window endpoint tests cover bounded footprint, cancellation, short/corrupt files, cheap cloning and resident entry materialization.
- Dual-filter complete export comparison matched old path (maximum error 0); cancellation and owned spool cleanup passed.
- Reported 8192×6144 / 93.12 mm / Glimmerglass 0.5 case: old field admission rejects; new native planner admits 272-row stripes at 512 MiB, estimated joint peak 535,615,928 bytes. This is a model, not measured phone RSS or GPU residency.

No phone speedup claim is made. The user's 50MP DNG was not available for a physical-device end-to-end test. Smaller stripes may incur extra GPU submissions; true driver memory and runtime require device validation. Existing CPU fallback and two historical geometry test expectations are not silently redefined by this feature.
