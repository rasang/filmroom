## 更新
- 全量接入 Adobe DNG SDK 1.7.1：所有 DNG 统一解码至场景线性空间，支持相机色彩配置文件、`BaselineExposure`、空间黑电平、标准光源标定、无损 JPEG、`DefaultScale` 与全部 8 种旋转裁剪方向，并在内存受限时启用匿名溢出缓冲。
- 扩展 RAW / DNG 光学镜头校正：支持畸变、暗角与色差（TCA）线性空间校正，优先采用内嵌参数，对符合白名单门控的原机文件提供离线 Lensfun 0.3.4 回退，并在「照片信息」中明确提示实际生效项。
- 新增「配置文件校正」开关：位于「调整」栏末尾（默认开启，支持四语、本地预设与 V2 二维码预设扩展），可一键开关 RAW / DNG 的畸变、暗角与色差校正并实时重显影。
- 整合首页实况（Live）动态预览、对比场景保持与直接导出，修复返回编辑器时的缩放视口与手势状态保留。
- 保留已授权照片的地理位置（GPS）元数据通过导入与普通 / 实况导出（诊断日志仅记录状态，不记录坐标）。
- 收敛大尺寸 GPU 物理光晕缓冲占用，补充导出准备与保存进度反馈，修复后台恢复后的放大细节刷新与已完成导出缩略图恢复。
